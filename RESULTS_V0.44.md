# v0.44 — Tagged QUEUED-Predecessor Authority

## Observe

v0.43 survives one additional live-prefix hop by publishing a second reverse-hop identity in superblock metadata. The surviving result is intentionally narrow: queue `[PP, P, T, S]`, with `PP` equal to the queue head, can relocate live physical tail `T` without queue traversal.

The next deeper state is already discriminating. In queue `[PPP, PP, P, T, S]`, the new physical tail after relocating `T` is `P`, and correct post-truncation authority requires `P.prev = PP`. Extending the v0.43 representation literally would require another superblock reverse-hop field for each additional supported prefix depth.

## Diagnose

A growing finite reverse window moves the queue-depth problem into metadata width rather than removing it. The missing primitive is not another special-case hop; it is a tagged current-neighbor predecessor edge attached to every QUEUED descriptor.

If each QUEUED descriptor has durable `(prev_page, prev_incarnation)` authority, the physical tail can validate its predecessor and that predecessor's predecessor by direct addressed reads regardless of how far the physical tail lies from the logical queue head.

The candidate must not smuggle an unbounded map into the superblock, discover predecessors by queue/history traversal, or weaken incarnation validation.

## First principle

Topology locality should be represented where the topology lives.

For a queue edge `A -> B`, current-state authority should be bidirectional and tagged:

- `A.next = (B.page, B.incarnation)`;
- `B.prev = (A.page, A.incarnation)`.

Then relocation of a directly addressed physical tail `T` can derive the new physical-tail predecessor from `P.prev` after validating `T.prev = P` and `P.next = T`, rather than from a fixed-depth superblock reverse window.

## Candidate solution

Test a v0.44 QUEUED-predecessor authority that is page-addressed and finite-width per descriptor. The representation may use descriptor-page slack or an equivalent page-addressed sidecar, but it must satisfy the same locality contract: predecessor lookup is by descriptor identity, not by queue walk.

Required maintenance paths:

- append: new descriptor `N.prev = old_tail`, and `old_tail.next = N`;
- FREE-head reuse: reused `N.prev = old_tail`, and `old_tail.next = N`;
- queue-head reclaim: new head publishes null predecessor authority;
- live-tail relocation: destination inherits both `T.prev = P` and `T.next = S`; `P.next` and `S.prev` are rewired to the destination; the new physical-tail authority is derived from `P.prev`;
- recovery: committed topology must recover scan-free and stale identities must remain rejected.

## Hypothesis

A tagged predecessor edge on every QUEUED descriptor is sufficient to relocate a live physical retirement-descriptor tail at queue depth greater than v0.43's finite reverse window with bounded direct work independent of the number of live prefix descriptors.

## Predictions

The candidate survives only if:

- unchanged v0.43 refuses the first five-node deeper-prefix state before descriptor I/O;
- v0.44 can relocate that physical tail without queue/history traversal;
- the queue remains doubly consistent after append, reuse, reclaim, and relocation;
- the old physical-tail and consumed FREE-destination identities are rejected after relocation/reuse;
- recovery after real process `SIGKILL` on predecessor-publication and relocation paths is exact, scan-free, and idempotent;
- scaling to multiple live-prefix depths holds bounded direct work rather than growing with queue depth;
- no unbounded reverse list or queue-sized mapping is embedded in superblock metadata.

## Planned discriminating geometry

Target a five-node live queue of the form:

`[PPP, PP, P, T, S]`

with:

- `T` the physical retirement-descriptor tail;
- `S = T.next` the logical queue tail;
- `P = T.prev`;
- `PP = P.prev`;
- `PPP` a deeper live prefix node proving that `PP` is not the queue head;
- one lower sole FREE relocation destination `D`.

The exact concrete page fixture will be frozen only after it is generated by the real implementation and survives the control/candidate comparison.

## Falsification controls

The experiment should include:

1. v0.43 control on the same deeper geometry, requiring refusal before descriptor I/O.
2. Positive v0.44 relocation with exact topology and direct-work accounting.
3. Bidirectional-edge validation before and after relocation.
4. Maintenance tests for append, FREE reuse, and queue-head reclaim.
5. Real process-crash matrices for edge publication and relocation.
6. Prefix-depth scaling showing queue-depth-independent descriptor work.
7. A negative case that refuses malformed/stale predecessor authority rather than traversing to repair it implicitly.

## Deliberate boundary

This target tests bounded tagged QUEUED predecessor authority for single-writer retirement topology. It does not yet claim composition with arbitrary multiple-FREE destination repair, multi-writer concurrency, hardware power-loss/torn-write correctness, or filesystem/device allocated-block reclamation.
